清楚的網頁設計，讓企業把話說明白。

企業官網往往要同時面對客戶、投資人與求職者。我擅長快速摸清一個陌生產業的邏輯，把龐雜、面向多種對象的資訊，整理成一眼讀懂的頁面。

色彩只用在需要被看見的地方，其餘交給留白與真實影像，讓內容本身成為主角；從資訊架構、視覺設計到前端建置，盡量讓設計稿與上線成品保持一致。

Service

01Information Architecture
資訊架構

理解產業與受眾，重新梳理選單與頁面層級，讓客戶、投資人與求職者都能用最短路徑找到需要的資訊。

02Visual Design
視覺設計

從品牌識別延伸色彩、字級與版面規則，以章節編號、英文浮水印與一致的卡片系統，建立長頁面的閱讀節奏。

03Web Build
前端建置

以 WordPress、Elementor Pro 搭配 HTML / CSS / JavaScript 完成建置與 RWD 調校，上線後也方便客戶自行維護。
